Ferrets Beverages Private Limited - static website

FILES
  index.html, privacy.html, terms.html, styles.css
  assets/ (logo.svg and product images)

TEST LOCALLY
  Open index.html in a browser (double-click it), or run:
    Windows : start index.html
    macOS   : open index.html
    Linux   : xdg-open index.html
  Optional local server:  python3 -m http.server 8000   then visit http://localhost:8000

UPLOAD TO SHARED HOST
  1. Log in to cPanel (or FTP) and open File Manager, then public_html.
  2. Upload all files and the assets folder, keeping the same structure.
  3. Open your domain and click every link in the header and footer.
  4. Check that these load: yourdomain/privacy.html and yourdomain/terms.html
